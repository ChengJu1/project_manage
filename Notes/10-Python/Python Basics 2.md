# Python基础-2

## 1. 列表（list）

### 1.1 定义
列表（List）是一种有序、可变的序列数据类型，用于存储多个元素的集合。它是 Python 中最灵活、最常用的数据类型之一，支持动态添加、删除、修改元素，且可包含不同类型的元素（如整数、字符串、列表等），适合处理需要频繁更新或有序存储的数据。

---
### 1.2 核心特点

1. 可变性（Mutability）列表创建后可直接修改元素（如修改指定索引的元素、添加新元素、删除元素），无需创建新列表。
2. 有序性（Order）列表中的元素按插入顺序排列，可通过索引（Index） 精准访问单个元素（索引从 0 开始，支持负数反向访问）。
3. 元素多样性可包含不同类型的元素（如 [1, "hello", True, [2,3]]），且允许重复元素。
4. 可迭代性可通过循环（如 for 循环）遍历列表中的每个元素。
5. 语法标识用 [] 包裹元素，元素之间用逗号分隔（如 [1, 2, 3]）。

---
### 1.3 基础操作

1. 列表创建
2. 访问列表元素：索引 / 切片，`lst[start:end:step]`（步长 step）,逆序切片：lst[::-1]，正序：[:]，[::]
3. 修改列表元素：`lst[0] = 新值`
4. 追加列表元素：
   - `append(x)`：末尾加一个
   - `extend(iter)`：末尾加多个
   - `insert(index, x)`：指定位置插入
5. 删除列表或列表元素：
   - `pop(i)`：删并返回值
   - `remove(x)`：删首次出现的值
   - `del lst[i]`：按索引删
   - `clear()`：清空
6. 列表长度：len(lst)
7. 判断列表元素是否存在：in、not in
8. 列表拼接和重复：`+ *`
9. 列表元素排序：`sorted() 返回新列表、sort() 原地修改`
10. 列表元素反转：`reverse()`
11. 统计列表指定元素次数：`count(x)`
12. 查询列表指定元素位置（索引）：`index(x)`
13. 统计列表的数值总和（均为数值元素）：`sum()`
14. 查询列表的最大值/最小值（均为数值元素）：`max()/min()`
15. 列表推导式：高效创建/过滤，`[x*2 for x in range(5)]）`、`[x*2 for x in range(5) if x%2==0]`
16. 枚举：`enumerate()`、`for index, val in enumerate(lst)`

---
### 1.4 嵌套列表

列表可包含其他列表作为元素，形成 “嵌套列表”（类似二维数组），常用于存储表格类数据。

示例：`matrix = [[1,2],[3,4]]`

## 2. 元组（tuple）

### 2.1 定义
元组（Tuple）是一种有序、不可变的序列数据类型，用于存储多个元素的集合。它与列表（List）类似，但核心区别在于不可变性—— 创建后无法修改元素，这使得元组在存储固定数据、保证数据安全等场景中更具优势。

---
### 2.2 核心特点

1. 不可变性（Immutability）元组创建后，无法添加、删除或修改元素（若元组包含可变元素如列表，列表内部可修改，但元组本身的元素引用不可变）。
2. 有序性（Order）元组中的元素按插入顺序排列，可通过索引（Index） 访问单个元素（索引从 0 开始，支持负数反向访问）。
3. 元素多样性元组可包含不同类型的元素（如整数、字符串、列表、元组等），且允许重复元素。
4. 轻量性元组比列表占用更少的内存，执行速度更快（因不可变特性，Python 对其优化更充分）。
5. 语法标识用()包裹元素（单个元素需在末尾加逗号，如(1,)，否则会被识别为普通括号）；也可省略括号（如1, 2, 3）。

---
### 2.3 基础操作

1. 创建元组
2. 访问元组元素：`tup[index]`
3. 元组的长度：`len(tup)`
4. 元组的拼接与重复：`+ *`
5. 判断元组的元素是否存在：`in / not in`
6. 元组解包：`a, b = (1, 2)`
7. 统计元组指定元素数量：`count(x)`
8. 查找元组指定元素的位置（索引）：`index(x)`
9. 元组的“不可变”：`append() / tup[0]=1`

## 3. 字典（dict）

### 3.1 定义
字典（Dictionary） 是一种无序、可变的数据类型，用于存储键值对（key-value）映射关系。它的核心特点是通过 “键” 快速访问对应 “值”，类似于现实生活中的字典（通过 “单词” 查找 “释义”），因此非常适合存储具有关联关系的数据。

---
### 3.2 核心特点

1. 键值对结构：每个元素由键（key）和值（value）组成，格式为 {key1: value1, key2: value2, ...}。
2. 无序性（Python 3.7+ 后为有序）：Python 3.7 之前字典元素无序，3.7+ 后保留插入顺序（但仍不支持索引访问）。
3. 键的唯一性：键不能重复，若重复定义，后定义的键值对会覆盖前面的。
4. 键的不可变性：键必须是不可变类型（如整数、字符串、元组），列表等可变类型不能作为键。
5. 值的多样性：值可以是任意数据类型（包括整数、字符串、列表、字典等），且可以重复。

---
### 3.3 基础操作

1. 创建字典：`{}`、`dict()`、推导式
2. 访问指定值：`d[key]`、`d.get(key, 默认值)`
3. 修改指定值：`d[key] = value`
4. 添加键值对
5. 删除键值对：`del`、`pop()`、`clear()`
6. 获取所有键：`keys()`
7. 获取所有值：``values()`
8. 获取所有键值对：``items()`
9. 更新字典：`update()`
10. 字典推导式：高效创建字典的核心语法（如`{k:v for k,v in zip(["a","b"], [1,2])}`）
11. 默认字典：`from collections import defaultdict`

举个例子：
```python
d = {}
d['张三'].append(90)
print(d)
# ----------------------------------
from collections import defaultdict
d = defaultdict(list)
d['张三'].append(88)
print(d)

```

---
### 3.4 嵌套字典
字典的值可以是另一个字典，形成 “嵌套字典”，适合存储层级结构的数据（如多级分类、用户信息等）

## 4. 集合（set）

### 4.1 定义
集合（set）是一种无序、不重复的可变数据类型，用于存储唯一元素的集合。它的核心特性是去重和高效的成员关系判断，适合用于需要快速查找、去重或进行集合运算（如交集、并集）的场景。

---
### 4.2 核心特点

1. 无序性：集合中的元素没有固定顺序，不能通过索引访问（与列表、元组不同）。
2. 唯一性：集合中不会有重复元素，自动去重。
3. 可变性：可以动态添加或删除元素（但集合的元素必须是不可变类型，如整数、字符串、元组等；列表、字典等可变类型不能作为集合元素）。
4. 高效性：判断元素是否在集合中（in操作）的时间复杂度为 O (1)，远快于列表的 O (n)。

---
### 4.3 基础操作

1. 创建集合 set()，{1,2}
2. 添加元素：`add(x)`、`update(iter)`
3. 删除元素：`remove(x)`、`discard(x)`、`pop()`、`clear()`
4. 集合运算：
   - 并集：`|`、`union()`
   - 交集：`&`、`intersection()`
   - 差集：`-`、`difference()`
   - 对称差：`^`、`symmetric_difference()`

5. 判断集合指定元素是否存在
6. 集合长度：`len(s)`

## 5. 深拷贝与浅拷贝

### 5.1 浅拷贝 (Shallow Copy)
浅拷贝的核心逻辑是“只抄表面，不抄内部”。它会构造一个新的复合对象，但仅仅是将原始对象中第一层元素的引用（内存地址）插入其中。
特点：新对象与旧对象的外层容器是独立的，但如果内部包含嵌套的可变对象（例如嵌套列表），它们依然共享同一块内存地址。修改嵌套对象时，新旧对象会相互影响。
常见实现方式：
切片操作：`new_list = old_list[:]`
工厂函数：`new_list = list(old_list)`
对象自带方法：`new_list = old_list.copy()`
标准库模块：`copy.copy(old_obj)`

---
### 5.2 深拷贝 (Deep Copy)
深拷贝的核心逻辑是“连根拔起，彻底独立”。它会递归地复制原始对象及其所有层级的子对象，创建一个与原始对象完全独立的新对象2。
特点：无论嵌套层级有多深，新旧对象之间都没有任何共享的内存引用。对深拷贝对象的任何修改，都绝对不会影响原始对象6。
常见实现方式：
标准库模块：`copy.deepcopy(old_obj)`

---
### 5.3 深拷贝和浅拷贝的代码实践

```python
from copy import deepcopy

# 直接赋值（本质：引用赋值）
a = [1,2,3]
b = a
b[0] = 'b'
print("【直接赋值】修改b后，a的值为:", a)
print("【直接赋值】修改b后，b的值为:", b)
print("【直接赋值】a的内存地址:", id(a))
print("【直接赋值】b的内存地址:", id(b))
print("【直接赋值】a的第一个元素内存地址:", id(a[0]))
print("【直接赋值】b的第一个元素内存地址:", id(b[0]))
print("【直接赋值】a的第二个元素内存地址:", id(a[1]))
print("【直接赋值】c的第二个元素内存地址:", id(b[1]))
print('='*50)

# 浅拷贝
a = [1,2,3]
c = a.copy()
c[0] = 'c'  # 实际是将c的第二个元素指向了一个新地址
print("【浅拷贝】修改c后，a的值为:", a)
print("【浅拷贝】修改c后，c的值为:", c)
print("【浅拷贝】a的内存地址:", id(a))
print("【浅拷贝】c的内存地址:", id(c))
print("【浅拷贝】a的第一个元素内存地址:", id(a[0]))
print("【浅拷贝】c的第一个元素内存地址:", id(c[0]))
print("【浅拷贝】a的第二个元素内存地址:", id(a[1]))
print("【浅拷贝】c的第二个元素内存地址:", id(c[1]))
print('='*50)

# 深拷贝
a = [1,2,3]
d = deepcopy(a)
d[0] = 888  # 修改内层列表元素
print("【深拷贝】修改d后，a的值为:", a)
print("【深拷贝】修改d后，d的值为:", d)
print("【深拷贝】a的内存地址:", id(a))
print("【深拷贝】d的内存地址:", id(d))
print("【深拷贝】a的第一个元素内存地址:", id(a[0]))
print("【深拷贝】d的第一个元素内存地址:", id(d[0]))
print("【深拷贝】a的第二个元素内存地址:", id(a[1]))
print("【深拷贝】d的第二个元素内存地址:", id(d[1]))
print('='*50)

# 浅拷贝 - 嵌套列表
a = [[1, 2], 3, 4]
c = a.copy()       # 浅拷贝
c[0][0] = 999  # 修改内层列表元素
print("【浅拷贝】修改内层后，原列表a:", a)
print("【浅拷贝】修改内层后，浅拷贝c:", c)
print("【浅拷贝】外层列表 a 地址:", id(a))
print("【浅拷贝】外层列表 c 地址:", id(c))
print("【浅拷贝】内层子列表 a 地址:", id(a[0]))
print("【浅拷贝】内层子列表 c 地址:", id(c[0]))
print('='*50)

# 深拷贝 - 嵌套列表
a = [[1, 2], 3, 4]
d = deepcopy(a)     # 深拷贝
d[0][0] = 888  # 修改内层列表元素
print("【深拷贝】修改内层后，原列表a:", a)
print("【深拷贝】修改内层后，深拷贝d:", d)
print("【深拷贝】外层列表 a 地址:", id(a))
print("【深拷贝】外层列表 d 地址:", id(d))
print("【深拷贝】内层子列表 a 地址:", id(a[0]))
print("【深拷贝】内层子列表 d 地址:", id(d[0]))
```
