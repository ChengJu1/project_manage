# Python基础-1

## 1. Python入门

### 1.1 Python 定义

Python 是一门解释型、面向对象、动态数据类型、跨平台的高级编程语言，设计强调「代码可读性」和「简洁易用」，是编程新手入门的首选，也被广泛应用于各类实战场景。

拆开解释：

- 解释型：不用编译，写完就能运行
- 高级语言：人类易读懂，不用管底层硬件
- 面向对象：一切都可以当作 “对象” 处理
- 动态类型：不用声明变量类型，赋值即定义
- 跨平台：Windows、Mac、Linux 都能跑

静态类型和动态类型区别？

- 静态类型（如 Java/C/C++）：变量声明时必须指定类型，且不能随便改，比如 int a = 10; 后，a 永远是整数，不能赋值字符串。
- 动态类型（Python/JS）：变量无需声明类型，赋值时才确定类型，且可随时修改。
---
### 1.2 Python 核心特点

- 简洁优雅：用极简的代码实现功能，可读性强。
- 换行缩进：不用大括号 {}，用换行缩进区分代码块。
- 动态类型：变量不用提前声明类型，想存什么就存什么。
---
### 1.3 Python 生态层面

Python内置功能丰富，自带大量实用模块（如 os 操作文件、requests 简化网络请求、math 处理数学计算），无需重复造轮子。

第三方库海量：PyPI（Python 包索引）覆盖：
    - 数据分析：Pandas、NumPy、Matplotlib
    - 人工智能：TensorFlow、PyTorch、Scikit-learn
    - Web 开发：Django、Flask、FastAPI
    - 自动化：Selenium（网页自动化）、PyAutoGUI（桌面自动化）、BeautifulSoup（爬虫）

### 1.6 Python相关事项

1. 项目路径：路径不能含中文、空格、特殊符号，避免编码报错
2. 文件命名：.py 文件名只能英文、小写、下划线，禁止数字开头、关键字命名，注意`test_`开头慎用，自动识别为测试脚本
3. 缩进规范：统一 4 个空格，不要混用 Tab 和空格，缩进错误直接报语法错，学习PEP8规范文档
4. 编码声明：文件顶部建议写 `# coding: utf-8`或* `# -*- coding: utf-8 -*-`，解决中文乱码，一般针对Python2的项目，因为Python2默认使用ASCII编码，Python3默认编码为UTF-8（不强制要求）
5. 运行方式：右键文件 → Run，不要直接运行文件夹
6. 注释：单行 #，多行 """ """或者单引号，注释不执行，用于说明逻辑

## 2. Python标准数据类型

### 2.1 变量

变量定义：程序中用于存储、表示和操作数据的命名内存单元。

通俗解释：
- 变量就像一个带标签的盒子
- 使用等号`=`赋值，格式为：`变量名 = 数据值`
- 盒子名字（变量名）：比如 `age`、`name`
- 盒子里的东西（数据值）：比如 20、"张三"
- 不用提前说盒子装什么（动态类型），想装数字就装数字，想装文字就装文字。
- 随时能换盒子里的东西：`age = 20` → `age = 21`

知识点：
- 命名规则：字母/数字/下划线，不能数字开头，区分大小写，禁止使用关键字（if、else、for、while、def 等）命名
- 输出变量值：`print(内容)`，可多值输出，逗号分隔自动加空格
- 查看变量类型：`type(变量名)`
- 支持同时为多个变量赋值，例如：`a = b = c = 1`，也可以为多个对象指定多个变量。例如：`a, b, c = 1, 2, "zhang"`
- 变量值互换：
```python
x, y = 10, 20
x, y = y, x
```

标准输入：
从终端获取用户输入的文本内容，是程序和用户交互最基础的方式。通俗解释，在程序运行时，会暂停等待用户打字，按下回车后，把用户输入的内容作为字符串返回给程序。
语法：`input()`，默认用户输入的文本内容为字符串类型，即程序接收的变量为字符串类型

---
### 2.2 数字（Number）

定义：用于表示数值，包含整数（int，如 10、-5）、浮点数（float，如 3.14、-0.5），支持算术运算（加减乘除、幂运算等）

整数（int）：没有小数部分的数字，包括正整数、负整数和零。

浮点数（float）：带小数部分的数字，或用科学计数法表示的数字。

不同进制表示：
- 十进制：如 `a = 10`。
- 二进制：以 `0b` 或 `0B` 开头，如 `d = 0b1010`（转换为十进制为 10）。
- 八进制：以 `0o` 或 `0O`开头，如 `e = 0o12`（转换为十进制为 10）。
- 十六进制：以 `0x` 或 `0X` 开头，如 `f = 0xa`（转换为十进制为 10）。

常见操作：
- 常见运算（加减乘除）：`+ - * /`
- 整除（向下取整）：`//`
- 整除（向上取整）：`math.ceil`
- 取模（求余）：`%`
- 幂运算：`**`
- 计算绝对值：`abs()`
- 计算四舍五入：`round()`


`round()`函数：采用 IEEE 754 标准推荐的“银行家舍入法”（Banker's Rounding）
核心规则是：
- 当需要舍弃的数字小于 5 时，舍去。
- 当需要舍弃的数字大于 5 时，进位。
- 当需要舍弃的数字正好是 5 时，会向最接近的“偶数”靠拢（即逢五看前一位，奇数进位，偶数舍去）。
- 在 `round(10.45, 1)` 中，保留一位小数，正好卡在 `10.4` 和 `10.5` 之间。因为 `10.4` 的尾数 `4` 是偶数，所以按照规则，它向偶数靠拢，最终保留了 `10.4`。

---
### 2.3 布尔值（Boolean）

定义：用于表示逻辑判断结果，仅含两个值：True（真）和 False（假），本质是特殊的整数（True 对应 1，False 对应 0），可进行算术运算，可通过int(布尔值)转换为0/1。
布尔值只有两个值：True / False，首字母必须大写

- 常见逻辑运算符：`and 且`、`or 或`、`not 非`
- 常用于：条件判断（if）、循环终止（for、while）

---
### 2.4 字符串（String）

定义：用于表示文本信息，由单个或多个字符组成，需用单引号、双引号或三引号包裹，支持多行文本。

核心特点：
1. 支持多种引号定义：单引号（' '）、双引号（" "）、三引号（''' ''' 或 """ """，支持多行字符串）。
2. 有序性：字符串中的字符按固定顺序排列，可通过索引（Index）访问单个字符（索引从0开始，支持负数表示反向访问）。
3. 可迭代性：可通过循环遍历字符串中的每个字符。
4. 支持转义字符：通过 \ 表示特殊字符（如 `\n 换行`、`\t 制表符` `\\ 反斜杠`）。
5. 不可变性：不允许直接修改某单个字符。

常见操作：
1. 字符串创建：单引号、双引号、三引号
2. 字符串访问：`str[index]`
3. 字符串拼接与重复：`+ *`，注意：仅支持同类型拼接 / 重复，字符串和数字不能相加
4. 字符串长度：`len()`
5. 字符串的单字符（元素）判断：`in/not in`
6. 字符串大小写转换：`lower()/upper()/capitalize()`
7. 字符串转义字符输出：`\t, \n, \\, \", \'`
8. 字符串删除空白字符：`strip()/lstrip()/rstrip()`
9. 字符串查找与替换：`find()/rfind()/replace()`
10. 字符串分割与拼接：`split()/join()`
11. 判断字符串类型：`isdigit()/isalpha()/isalnum()`
12. 字符串格式化输出：f-string（推荐）`f"文本内容:{变量名}"`、`%`
举个例子：`print("Hello!%.3f" % 3.1415926)`

13. 字符串切片：
基本语法：`str[start: end: steps]`
切片采用“左闭右开”原则，其中str[0]表示取第一个字符，支持负数索引str[-1]表示取最后一个字符

14. 切片、访问的注意事项：
str[:100]、str[100]（数组越界报错）、str[100:]

### 2.5 数据类型转换

将一种数据类型转换成另一种数据类型，比如用户输入整数100，转换为浮点100.0或者转为字符串"100"等情况。
例如：

### 2.6 不可变类型（Immutable）
在 Python 中，常见的不可变类型包括 int（整数）、bool（布尔值）、str（字符串）、float（浮点数）以及 tuple（元组）。
修改的本质：当我们对 `int`、`bool` 或 `str` 进行所谓的“修改”时，Python 实际上是在内存中开辟了一块新的内存地址空间，把新数据放进去，然后把变量名这张“链接”指向新地址上。原来的数据依然留在原地（直到被垃圾回收清理掉）。

Python通过`id(变量名)`可查看变量的内存地址

```python
# 1. 整数 (int) 的演示
print("--- 整数 (int) 演示 ---")
a = 10
print(f"初始值: {a}, 内存地址(id): {id(a)}")

a = a + 5  # 看似修改，实则创建新对象
print(f"修改后: {a}, 内存地址(id): {id(a)}")
print("结论：内存地址发生了变化，说明创建了新的整数对象！\n")

# 2. 字符串 (str) 的演示
print("--- 字符串 (str) 演示 ---")
s = "Hello"
print(f"初始值: {s}, 内存地址(id): {id(s)}")

s = s + " World"  # 字符串拼接，创建新字符串
print(f"修改后: {s}, 内存地址(id): {id(s)}")
print("结论：内存地址发生了变化，原字符串未被修改！\n")

# 3. 布尔值 (bool) 的演示
print("--- 布尔值 (bool) 演示 ---")
b = True
print(f"初始值: {b}, 内存地址(id): {id(b)}")

b = False  # 重新赋值
print(f"修改后: {b}, 内存地址(id): {id(b)}")
print("结论：True 和 False 在内存中是不同的对象，赋值即切换指向！")
```
