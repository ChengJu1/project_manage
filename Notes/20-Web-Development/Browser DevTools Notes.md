# 网页基础-开发者工具补充

### Elements 元素面板（改页面 HTML+CSS）

作用：查看、实时修改网页 DOM 结构与样式，不用改本地代码就能预览效果

- 左侧：HTML 树形结构，双击文字 / 标签可直接修改，删除标签、新增元素
- 右侧 Styles：当前选中元素的 CSS 样式，可勾选禁用样式、改颜色 / 尺寸 / 边距、新增 CSS 属性
- 实用技巧：改完刷新页面会重置，适合临时调试布局、配色、字体

### 2. Console 控制台（打印日志、执行 JS 代码）

作用：调试 JavaScript、看报错、手动运行代码

- `console.log("输出内容")`：打印变量、接口返回数据
- 报错红色文字：定位 JS 代码出错的文件 + 行数，快速修复逻辑 bug
- 直接输入 JS 代码回车执行：比如获取页面所有按钮、修改页面文字

### 3. Sources 源代码面板（网页全部源码）

作用：查看网页加载的 JS/CSS/HTML 源文件，断点调试 JS 逻辑

1. 文件目录：网页所有静态资源（js 脚本、css 样式、图片、页面 html）
2. 断点调试：给 JS 代码加断点，刷新页面后代码会暂停，一步步看变量变化、函数执行流程，排查逻辑漏洞
3. 格式化代码：网页压缩后的一行 JS，点击`{}`美化成可读格式

### 4. Network 网络面板

- **选择元素图标**：点击后再点网页任意区域，自动跳转到 Elements 面板定位对应 HTML 代码，快速改页面样式。
- **设备模拟**：切换手机 / 平板 / 电脑尺寸，调试移动端适配。
- **截图按钮**：截取整页 / 可视区域 / 选中 DOM，你截图就是在这里截的。
- 搜索：网页上的元素文本信息

这张图核心就是这个面板，专门抓**网页所有请求**（图片、接口、js、css、视频等）

#### （1）顶部筛选栏（截图上方）

- **过滤器**：输入关键词，只展示名称匹配的请求，快速过滤目标接口
- **无限制 / 节流**：网络限速模拟（3G / 离线 / 自定义网速），测试弱网下页面加载卡顿问题
- **反转**：反向筛选
- **增加筛选条件**：按请求状态码、大小、时间过滤
- **分类标签（全部 / Fetch/XHR/CSS/JS/Img…）**

#### （2）请求列表表头（名称、状态、类型、发起程序、大小、时间、履行者）

1. **名称**：资源文件名 / 接口地址
2. **状态（核心！）**
   - `200`：请求成功（截图大量 200 接口）
   - `304`：缓存命中，服务器不重复传输资源（截图里所有图片、css 都是 304，浏览器本地缓存读取，加速页面）
   - `4xx`：客户端错误（404 资源不存在、403 无权限）
   - `5xx`：服务器后端报错
3. **类型**：资源格式 `png/jpeg/script/stylesheet/fetch`
4. **大小**：资源加载体积，`(memory cache)`= 内存缓存、`(disk cache)`= 硬盘缓存，不走网络
5. **时间**：加载耗时，数值越大代表加载越慢
6. **发起程序**：哪个文件触发的这个请求（比如`notice.css`加载图片、`layui.js`发起接口）

#### （3）底部总览栏（截图最下方）

```
64次请求 | 已传输101kb | 3.1MB资源 | 完成26.7分钟 | DOMContentLoaded:612ms | 加载:760ms
```

- 请求数：页面一共发起多少次网络请求
- DOMContentLoaded：HTML 结构加载完成时间
- 加载：页面所有资源（图片、脚本、接口）全部加载完毕总耗时，数值越低页面打开越快

#### （4）Network 高频实用操作

1. **Preserve log（保留日志）**：勾选后刷新页面不清空请求列表，调试跳转页面、表单提交必备
2. **禁用缓存（Disable cache）**：勾选后刷新强制重新加载所有资源，不走浏览器缓存，避免改完代码不生效
3. **右键请求 → 复制 → 复制为 fetch/cURL**：直接把接口请求复制到 Postman、后端代码复现请求
4. **查看请求详情**：点击任意接口，右侧出现 Headers（请求头、响应头）、Preview（返回数据预览）、Response（原始返回内容）、Timing（各阶段耗时）

### 5. Performance 性能面板

录制页面加载、滚动、点击操作，分析页面卡顿、JS 执行阻塞、渲染慢的根源，优化网页速度。

### 6. Memory 内存面板

查看网页内存占用，排查内存泄漏（页面越用越卡、占用内存持续飙升）。

### 7. Application 应用面板

管理网页本地存储：Cookie、LocalStorage、SessionStorage、缓存、数据库，可手动增删改查登录 token、本地缓存数据。

### 8. Lighthouse 性能打分

一键生成网页综合报告：性能、可访问性、SEO、最佳实践打分，给出优化建议。
